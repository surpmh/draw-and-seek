# 캔버스 원본

`artwork.png`는 새 놀이공원 도안의 3840×2160 PNG 원본이다. 원본 파일은 리사이즈하지 않고 보관한다.

로컬 타일은 `npm run seed -- artwork.png`로 원본 크기에 맞춰 생성한다. 출력은 512px 타일 57개이며 `data/tiles/`는 생성물이므로 Git에서 제외한다.

운영 캔버스의 좌표 크기는 기존 그림의 위치를 보존하기 위해 4096×2305로 유지한다. 운영용 타일 생성 시 원본을 이 좌표 크기에 맞춰 렌더링하고, 기존 미발견 그림을 새 배경 위에 재합성해야 한다. 원본 크기로 운영 메타데이터를 줄이면 기존 그림 일부가 캔버스 바깥에 남게 된다.

교체 순서는 기존 DB·Storage 스냅샷 보관, 새 배경 타일 생성, 미발견 그림 재합성, 타일 업로드, 메타데이터 확인, `bump_canvas_version` 호출이다. 타일 업로드가 모두 끝난 뒤에만 버전을 올려 브라우저의 이전 캐시를 무효화한다. 단순히 `sync-storage`로 로컬 서빙 타일을 운영에 덮어쓰면 운영의 그림이 지워질 수 있으므로 운영 그림을 기준으로 합성한다.
