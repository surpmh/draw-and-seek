# 업로드 직후 그림 표시 유지

- 원인: 저장 API는 DB 기록 직후 응답하고 타일 합성은 응답 뒤에 수행한다. 클라이언트는 저장 응답과 동시에 배치 미리보기를 지워, 새 타일이 도착하기 전까지 그림이 사라졌다.
- 수정: 저장 성공 시 그림의 이미지와 배치 좌표를 임시로 유지한다. `TileLayer`가 저장 시점보다 새로운 버전의 현재 화면 타일을 모두 로드했다고 알릴 때 임시 표시를 제거한다. 버전 변경만으로는 제거하지 않는다.
- 예외 처리: 저장 실패 시 기존 편집 상태를 유지한다. 목록 조회 실패로는 임시 그림을 지우지 않는다. 성공한 목록 조회에서 발견·삭제된 그림은 제거하며, 요청 중 새로 저장된 그림을 오래된 목록 응답으로 지우지 않는다. 임시 이미지는 포인터 이벤트를 가로채지 않아 찾기와 화면 이동이 계속 동작한다.
- 회귀 테스트: `tests/upload-visibility.browser.cjs`가 실제 앱을 로컬 브라우저로 실행하고 API를 모킹한다. 수정 전에는 데스크톱과 모바일 모두 저장 직후 이미지 개수가 0이 되어 실패했다. 저장 실패, 합성 지연, 타일 로딩 지연, 목록 조회 실패, 타일 전환 전 발견을 확인한다.
- 실행: 로컬 개발 서버를 실행한 뒤 `TEST_BASE_URL=http://127.0.0.1:3100 node --test tests/upload-visibility.browser.cjs`. 실제 DB와 저장소에는 접근하지 않는다.
- 검증 결과: 브라우저 회귀 테스트 2개(1440px·390px), 기존 자동 테스트 45개, `npx tsc --noEmit`, `git diff --check` 통과.
- 관련 경로: `components/HiddenCanvasApp.tsx`, `components/CanvasViewport.tsx`, `components/TileLayer.tsx`.
