# 최소 잉크 면적 강화

- 원인: 투명 픽셀은 이미 제외하지만 최소 면적 30px²가 낮아 기본 펜의 점 세 개(약 46px²)가 통과했다.
- 변경: 최소 색 면적을 512px²로 높이고, 잉크 영역의 기울기를 보정한 최소 폭 24px 조건을 추가했다. 기존 최소 긴 변 48px 조건도 유지한다.
- 구현: `lib/ink-metrics.ts`가 보이는 픽셀의 면적과 볼록 껍질을 계산한다. 외곽을 감싸는 평행선의 최소 간격으로 직선·대각선을 검사한다. 클라이언트와 서버가 같은 측정 함수와 기준을 사용한다.
- 검증: `npm test`의 API 회귀 테스트 16개와 `npx tsc --noEmit` 통과. 폭 검사 전에는 가로·세로·대각선·기울어진 직선 차단 테스트 4개가 실패했다.
- 테스트 범위: 점 세 개(5·6·12px 펜), 511/512px² 및 23/24px 경계, 직선 네 방향, 가는 윤곽선, 원본 해상도 1/2/3배, 회색조 PNG. DB와 저장소를 모킹해 실제 업로드는 발생하지 않는다.
- 관련 경로: `components/HiddenCanvasApp.tsx`, `lib/ink-square.ts`, `app/api/drawings/route.ts`. 폭 부족 안내 문구는 지원 언어 7개에 추가했다.
- 범위: 기하학적 크기와 색 면적으로 판정한다. 의미 있는 그림인지까지 분류하지는 않는다.
